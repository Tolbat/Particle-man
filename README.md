# Particle-Man

Particle-Man is a procedural neon maze chase for Atari Jaguar, built with
JagStudio and RAPTOR. Player, threats, fruit, walls, collectibles and PCM sound
effects are generated by code; no pre-rendered gameplay sprites or sampled
gameplay audio are used.

## Release-candidate status

Current source: **C19e GameDrive-save candidate**. C19 closes the release self-audit
without changing the accepted movement cadence, D-pad rules, campaign size,
roster, Object Processor/GPU split or finite starting inventory. Performance
diagnostic code and controls have been removed from the runtime; the shipping
particle scan remains fixed at the hardware-selected 64-record cap.

C19d corrected stopped-corner input. C19e replaces the incompatible JagStudio
2 KB EEPROM helper with a project-local 64-word protocol for Particle-Man's
current 128-byte GameDrive save configuration. Real-hardware power-cycle
retention remains the final Beta blocker.

C19b preloads the complete Credits, Title and Hall pages behind an advancing
`POWERING PARTICLE-MAN` startup card. Attract transitions now publish an
already-built phrase-aligned page at VBL instead of constructing the next page
while the old one appears frozen. C, B, A or Pause on Credits or Hall goes
immediately to Title; a separate subsequent press starts the selected run.

C13 is the latest user-accepted smooth real-Jaguar gameplay baseline. C14-C16
then made contained input and presentation corrections: held-D-pad movement,
symmetric quarter-tile corner grace, finite starting actions, physical `C B A`
labels, a waiting first-run instruction card, single-action button arbitration
and independent title-letter colors. Those corrections, plus the C17 release
configuration, plus the C18 completion work, require one final real-hardware
acceptance run before a ROM is called final.

## Game

- Ten connected 24x23 landscape mazes span a 50-level campaign.
- Four classic threats grow into an eight-enemy roster with Vector Wraith,
  Crawler Shade, Otto Echo and Flipper Phantom.
- Later chapters add Spark Chain, Fruit Fever, Warp Gates, Ghost Alarm,
  Ghost Centipede and Particle Storm.
- Each fruit objective generates a different silhouette. Levels 1-25 require
  two fruit and levels 26-50 require three; a missed fruit returns after a
  cooldown. Completing the HUD fruit box unlocks unlimited Dash for that level.
  Fruit Fever clearly
  starts a timed pellet magnet, Prism Pressure visibly builds to three speed
  steps until Pulse clears it, and Particle Storm warns before reversing every
  released threat.
- The Object Processor carries the persistent canvas, procedural actors, wakes,
  pickup glint and score popup. RAPTOR's GPU particle surface is reserved for
  bounded event impacts.
- Top-five scores and the highest legitimately unlocked level persist in
  cartridge save memory.
- Runs start with three lives. Crossing 15,000 and 50,000 points awards one life,
  up to five.

## Controls

- D-pad: hold to move; turns buffer within a small before/after-junction window.
- Pause or Option: pause/resume.
- STAR or HASH: submit a qualifying score, clear the current game, and return
  to the title.
- Keypad 8: toggle all sound effects.
- C: Shield; starts at 1/1 and a power pellet refills it.
- B: Pulse; starts at 2/2 and fruit adds one.
- A: Dash; starts ready, then rapidly recharges on its visible badge meter. A
  power pellet refills it immediately.

The first level-one instruction card waits for a deliberate C/B/A,
Option/Pause or D-pad press. Later READY cards remain timed. Simultaneous action
presses spend at most one charge. Dash is not consumed while stationary, and
Pulse cannot consume another charge while its stun is already active.

## Arcade secrets

The release candidate intentionally retains two manual-only secrets. Neither
code is advertised in the Hall of Sparks:

- Every cold boot starts with LIMITED actions. During any interactive screen,
  enter `2600` to toggle LIMITED/UNLIMITED. Feedback changes only a small status
  line or the HUD; it never forces a screen rebuild. `5200` is removed as
  redundant. C, B and A are the only gameplay actions.
- Enter `99LLL`, where `LLL` is `001`-`050`, to jump to a campaign level with
  all actions filled. For example, `99042` loads level 42. Either secret marks
  the whole run as cheated: it cannot save a score or unlock progression and
  level 50 shows the alternate ending.

The title also selects any legitimately unlocked level. A start above level 1
begins at zero and cannot enter the Hall, but remains a legitimate campaign
run, can unlock the next level and receives the normal ending. The title labels
level 1 `FULL SCORE RUN` and later starts `CONTINUE NO HIGH SCORE`.

Keypad 8 toggles sound. Keypad 1-7 have no standalone gameplay behavior.

## Build and acceptance

Build the normal JagStudio C project `particlepac`. Under the current testing
agreement, the user compiles and tests on real Jaguar hardware; Codex does not
compile or launch the game. Run `tools/validate_project.ps1` for non-compiling
checks, then follow `HARDWARE_TESTS.md` for the final release-candidate run.
