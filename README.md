Particle-Man is a procedural neon maze-chase game for Atari Jaguar, built with JagStudio and RAPTOR. Features a 50-level campaign, generated point-cloud graphics and PCM audio, eight distinct enemies, persistent scores and progression. Pre-release candidate—real Jaguar testing is in progress.

# Particle-Man

Particle-Man is a procedural neon maze-chase game for the Atari Jaguar, built with JagStudio and RAPTOR.

Explore a 50-level campaign filled with evolving mazes, distinct enemy personalities, collectible fruit objectives, rechargeable abilities, escalating chapter mechanics, persistent progression, and an arcade-style high-score system.

## Development Status

Particle-Man is currently a release candidate undergoing final testing on real Atari Jaguar hardware.

The game is feature-complete, but the final public ROM will not be published until the complete hardware acceptance checklist passes.

## Features

- 50-level campaign divided into ten gameplay chapters
- Ten distinct procedural maze layouts
- Four classic ghost personalities
- Four advanced arcade threats:
  - Vector Wraith
  - Crawler Shade
  - Otto Echo
  - Flipper Phantom
- Ghost Centipede articulated enemy
- Spark Chain scoring system
- Fruit Fever pellet magnet
- Warp Gates
- Ghost Alarm
- Prism Pressure
- Particle Storm
- Rechargeable Dash
- Prism Pulse
- Protective Shield
- Chapter-specific procedural fruit
- Two-fruit objectives on levels 1–25
- Three-fruit objectives on levels 26–50
- Persistent top-five Hall of Sparks scores
- Persistent campaign progression
- Separate normal and humorous cheat endings
- NTSC and PAL timing support

## Controls

| Control | Action |
| --- | --- |
| D-pad | Move and buffer turns |
| C | Shield |
| B | Prism Pulse |
| A | Dash |
| Pause or Option | Pause or resume |
| STAR or HASH | Reset the game and return to the title |
| Keypad 8 | Toggle sound |

The controls are always presented in the Jaguar controller’s physical **C B A** order.

## Abilities

### Shield — C

Absorbs one enemy collision. Power pellets refill Shield.

### Prism Pulse — B

Temporarily freezes vulnerable threats and clears Prism Pressure. Fruit adds one Pulse charge.

### Dash — A

Provides a short burst of speed and recharges through the visible HUD meter. Power pellets refill Dash immediately.

Completing the level’s fruit objective unlocks unlimited Dash for the remainder of that level.

## Procedural Presentation

Particle-Man does not use pre-rendered gameplay sprites.

The following elements are generated by code:

- Particle-Man animation
- Ghost and specialist-enemy animation
- Ghost Centipede body segments
- Fruit silhouettes
- Maze graphics
- Collectibles and power pellets
- Player and enemy energy fields
- Particle effects
- Event sound effects

Gameplay imagery is displayed through the Jaguar Object Processor, while RAPTOR’s GPU manages the bounded particle-effect surface.

All sound effects are generated into memory during startup. The absence of background music is intentional, preserving the focused arcade soundscape.

## Campaign Structure

Every five levels introduces a new chapter identity, maze layout, mechanic, enemy, or combination of systems.

Later chapters combine previously introduced mechanics rather than simply changing colors or enemy speed.

Level 50 includes the final Particle Bonus, ending presentation, score handling, progression save, and return to the Hall of Sparks.

## Saving and Progression

Particle-Man stores:

- The five highest qualifying scores
- The highest legitimately unlocked level

A full high-score run begins at level 1.

Previously unlocked levels may be selected from the title screen for continued campaign play. Continued runs begin with a fresh score and cannot enter the Hall of Sparks, but they can unlock additional levels and receive the normal ending.

## Building

Particle-Man is a standard JagStudio C project.

1. Install and configure JagStudio.
2. Place the project in the JagStudio C projects directory.
3. Open or build the `ParticlePac` project using the normal JagStudio workflow.
4. Test the resulting ABS or ROM on compatible Atari Jaguar hardware or development equipment.

The authoritative development target is real Atari Jaguar hardware.
